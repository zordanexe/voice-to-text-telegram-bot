# Бот транскрибатор Голос в Текст

Продукт: Telegram-бот, который принимает голосовое сообщение и возвращает текст.
Пользователь: владелец малого бизнеса, которому удобно диктовать заметки голосом.
Проблема: голосовые заметки неудобно вручную переносить в текст и рабочие задачи.
Критерий готовности первой версии: бот принимает voice-сообщение и возвращает распознанный текст без ручной расшифровки.

Статус: выбрана идея и создана отдельная папка проекта для прохождения курса.

## Возможности первой версии

- команда `/start` объясняет, как пользоваться ботом;
- бот принимает голосовые сообщения Telegram;
- аудио отправляется в OpenAI Speech-to-Text;
- распознанный текст возвращается в тот же чат;
- временный аудиофайл удаляется после обработки;
- при ошибке пользователь получает понятное сообщение.

## Запуск

Требуется Python 3.11 или новее.

1. Создайте бота через `@BotFather` и получите токен.
2. Создайте API-ключ OpenAI.
3. Создайте виртуальное окружение и установите зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и заполните секретные ключи.
5. Запустите бота:

   ```powershell
   python bot.py
   ```

6. Откройте бота в Telegram, отправьте `/start`, затем голосовое сообщение.

Секретные ключи не добавляются в Git: файл `.env` исключён через `.gitignore`.
